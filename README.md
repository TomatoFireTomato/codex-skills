# TomatoFire Codex Marketplace

A public Codex plugin marketplace for reusable skills and related tooling.

## Marketplace Structure

```text
.
├── .agents/plugins/marketplace.json
└── plugins/
    └── japanese-whisper-subtitle-repair/
        ├── .codex-plugin/plugin.json
        └── skills/
            └── subtitle-manual-ja-zh/
                ├── SKILL.md
                ├── agents/openai.yaml
                └── scripts/srt-tool.mjs
```

Each directory under `plugins/` is an independently installable Codex plugin. A plugin may contain one or more skills. Add future plugins under `plugins/<plugin-name>/` and register them in `.agents/plugins/marketplace.json`.

## Add Marketplace

In Codex, open **Plugins**, choose **Add plugin marketplace**, and enter:

```text
Source: https://github.com/TomatoFireTomato/codex-skills.git
Git reference: main
Sparse path: leave empty
```

The marketplace identifier is `tomatofire-codex-plugin-marketplace`.

## Available Plugins

### `japanese-whisper-subtitle-repair`

Repairs Japanese `.srt` subtitles generated by Whisper or other ASR systems. It detects structural and ASR risks, verifies official Japanese terminology, audits every reviewed block, and writes a validated Japanese-only corrected SRT.

Included skill:

- `$subtitle-manual-ja-zh`

Example prompts:

- `用 $subtitle-manual-ja-zh 修正这个 Whisper 生成的日文 SRT，只输出日文修正版`
- `检查这个日语 ASR 字幕的幻觉重复、专名和时间轴`

## Update Workflow

For marketplace maintainers:

1. Update the plugin files.
2. Refresh the plugin version cachebuster:

```bash
python3 ~/.codex/skills/.system/plugin-creator/scripts/update_plugin_cachebuster.py plugins/japanese-whisper-subtitle-repair
```

3. Validate the plugin and skill.
4. Commit and push the marketplace repository.

For installed users:

1. Refresh or update the Git marketplace in Codex.
2. Reinstall or update `japanese-whisper-subtitle-repair` when an update is shown.
3. Start a new Codex thread so the updated skill is loaded.

Do not keep a standalone copy of the same skill in `~/.codex/skills` while the plugin version is installed, because duplicate skill names can make the active source ambiguous.

## Development

Run the subtitle tool from the repository with:

```bash
node plugins/japanese-whisper-subtitle-repair/skills/subtitle-manual-ja-zh/scripts/srt-tool.mjs inspect /path/to/file.srt
```

Validate before publishing:

```bash
python3 ~/.codex/skills/.system/plugin-creator/scripts/validate_plugin.py plugins/japanese-whisper-subtitle-repair
python3 ~/.codex/skills/.system/skill-creator/scripts/quick_validate.py plugins/japanese-whisper-subtitle-repair/skills/subtitle-manual-ja-zh
node --check plugins/japanese-whisper-subtitle-repair/skills/subtitle-manual-ja-zh/scripts/srt-tool.mjs
```

## Adding Another Plugin

Use the plugin scaffold so manifests and marketplace entries remain valid:

```bash
python3 ~/.codex/skills/.system/plugin-creator/scripts/create_basic_plugin.py <plugin-name> \
  --path ./plugins \
  --with-skills \
  --with-marketplace \
  --marketplace-path ./.agents/plugins/marketplace.json
```

The scaffold appends the new plugin to the marketplace. Keep plugin names in lower-case hyphen-case and validate each plugin before publishing.
